# Handwritten Digit Classifier

Classifies handwritten digits (0–9) using a Random Forest model trained on the MNIST digits dataset.

**Accuracy:** 97% on test set  
**Model:** Random Forest (100 estimators)  
**Libraries:** scikit-learn, matplotlib, seaborn

## What it does
- Loads and visualises the MNIST digits dataset
- Trains a Random Forest classifier
- Evaluates performance with a confusion matrix
- Predicts individual digits from test images

## Run it
pip install scikit-learn matplotlib seaborn notebook  
jupyter notebook digit_classifier.ipynb
